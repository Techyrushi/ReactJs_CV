## Run this portfolio locally

This site is built with Next.js 14, React 18, and Tailwind CSS.

```bash
git clone https://github.com/Techyrushi/ReactJs_CV.git
cd ReactJs_CV
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally. To create and run a production build:

```bash
npm run build
npm start
```
